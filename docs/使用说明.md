# Project Focus Manager 使用说明

> 这份说明只讲「怎么用」，不涉及代码。项目还在开发中，下面标注了每一块目前的状态。

## 一、程序放在哪

- 程序：`src\FocusManager.App\bin\Debug\net10.0-windows\ProjectFocusManager.exe`
- 数据：和程序同一层目录里的 `data\focus.db`（设置页里能看到准确路径，也能一键打开文件夹）
- 备份：`data\backups\`，在设置页点「立即备份一份」就会生成一份

学习记录只存在这台电脑上，不会上传。

## 二、开始一次专注

1. 打开程序，左侧点「专注」。
2. 在「这次专注哪个项目？」里选一个项目；没有就点「新建项目」。
3. 在「本轮主要使用哪个学习软件？」里选这次主要用的软件（可以先不选，不影响计时）。
4. 需要同时开好几个程序时，在「还要一起用哪些程序？（可选）」里点「添加辅助程序」，
   一个项目可以配好几个。配过一次就会记住，下次开始这个项目自动带上。
5. 点「开始专注」，计时从 00:00:00 开始往上走，不设上限。

计时按真实时间算，切到别的合法软件不会停。窗口关掉了也照样在走（见下面「托盘与关闭」）。

### 辅助程序是什么

有些事一个程序干不完：主程序是 CCtalk 在上课，笔记要写在 Obsidian 里，教材是另一个 PDF 阅读器。
「辅助程序」就是告诉程序「这几个都算本轮的学习环境」，切过去不会弹提醒。

- 辅助程序挂在项目上：给「英语」配了 Obsidian 和 PDF 阅读器，下次开始「英语」自动带上。
- 专注已经开始也能补：专注页点「添加」、或者在离开提醒里点「添加辅助程序」，加完立刻生效，不用重新开始这一轮。
- 加了之后这一轮会记下来用了哪些程序，项目记录里能看到。
- 主程序和辅助程序在「离开提醒」里都算合法，不会被当成「切出去了」。

## 三、暂停与继续

- 点「暂停一下」，先选一个暂停原因（喝水 / 临时有事 / 查找资料 / 其他），点「开始暂停」。
- 暂停期间不计入专注时间。
- 点「继续专注」接着算。

暂停超过 5 分钟（可在设置里改成 10 分钟、15 分钟或关掉），会弹出一个「该回来了」的小窗口，问你要不要回来：

- 点「回到项目」：程序会先去把你本轮的学习软件叫到前台。
  - 软件开着 → 直接切过去，然后从暂停的地方继续计时。
  - 软件已经关了 → 弹一个「还没找到学习软件」的提示，告诉你先去打开它；这一轮**保持暂停**，不会偷偷开始计时。你打开之后点「我已打开，继续专注」，程序会再检查一次。
  - 程序**只会激活已经开着的软件，绝不会替你启动任何程序**，也不会去动 Obsidian 的库（Vault）。
- 点「结束本次专注」：进入总结页面，已经专注的时间会保留。

这个提醒只弹一次，不会自动帮你继续，也不会自动结束。

## 四、结束这一轮

点「结束本次专注」→ 填写「本轮完成了什么」（必填）→ 可以再写点心得 → 点「保存并结束」。

保存后，这一轮的有效时间会加到项目累计时间里，可以在「项目记录」里看到。

长文本框会随着内容自动长高（三四行起步，长到十行左右开始出现滚动条），不会把别的按钮挤出屏幕。

### 不到 5 分钟的一轮

有效专注时间不到 5 分钟时，程序会先问一句「这一轮要记下来吗？」：

- 点「作废这一轮」：这一轮丢掉，不算进项目时间，也不留记录。
- 点「仍然保存」：照常记下来，适合「先记一笔再说」的情况。

### 作废本轮

专注进行中（或暂停中）点「作废本轮」，这一轮整个丢掉：

- 不记时间，不留记录，项目累计时间不变。
- 做错了找不回来，所以会先问一次。
- 和「结束本次专注」的区别：结束是要留下记录的，作废是当作没发生过。

程序崩溃后恢复出来的那一轮不受 5 分钟规则影响，已经发生的时间照样保留。

## 五、项目记录

左侧点「项目记录」：

- 左边是项目列表，右边是这个项目的累计专注时间、每天专注了多久、每一轮的记录与心得。
- 每一轮的「本轮进度」和「心得」都可以用鼠标选中，也可以 Ctrl+A 全选、Ctrl+C 复制（只读，改不动已经保存的内容）。
- 每条记录右上角有个小垃圾桶图标，点它可以只删掉这一次专注。项目本身和别的记录都还在，项目累计时间会相应减少，删之前会问一次。
- 想删掉一个项目，点右上角「删除这个项目」，会先告诉你这个项目里有多少记录，再让你确认一次。
- 如果这个项目还有一轮专注没结束，会提示你先结束它。

## 六、应用管理

左侧点「应用管理」：

- 「选择程序文件添加」：直接挑一个 .exe。
- 「从正在运行的程序中添加」：从当前开着的窗口里挑一个，不用自己找路径。
- 每行可以「修改」「停用 / 启用」「删除」。删除只删掉这条登记，不会删掉那个程序本身。
- 内置了 Obsidian、百度网盘、CCtalk 三条，一开始没有路径，靠进程名识别。

注意：**登记过不等于获得了使用权限**。每次专注只放行你本轮选的那一个主程序、这个项目配的辅助程序，再加上 Obsidian、程序自己的窗口和必要的 Windows 系统窗口。

## 七、离开学习环境时的提醒

专注过程中如果切到别的软件（微信、浏览器等），会弹一次「你似乎离开了当前学习环境」：

- 点「返回项目」：提醒关掉，计时继续。
- 点「确认切换」：再问你要「暂停本次专注」还是「结束本次专注」。
- 点「添加辅助程序」：如果你本来就该用这个程序（比如查资料的浏览器、看教材的阅读器），
  把它加进本轮就行。选择器会**默认选中刚才那个程序**，确认之后提醒关掉，这一轮再切到它就不弹了。
- 你可以完全不理它，计时照常走。

**同一段离开只会提醒一次**：不管你在这个软件里待多久、在几个不允许的软件之间来回切，都不会反复弹。只有等你回到本轮允许的软件（比如你选的那个学习软件、Obsidian、程序自己的窗口）之后，提醒状态才会重置；之后再离开，才会重新提醒。

用百度网盘、CCtalk 全屏看视频时不会弹提醒，退出全屏后才补上。

## 八、托盘与关闭

程序支持三种不同的窗口行为，别弄混：

- **最小化（点右上角的「—」）**：窗口缩到任务栏，点任务栏上的图标就能还原，计时继续。
- **最小化到托盘**：窗口藏起来，只在右下角托盘留一个图标，计时继续。入口是托盘右键菜单里的「最小化到托盘」。
- **点右上角的关闭按钮（×）**：默认会弹一个小窗口问你想怎么办——「最小化到系统托盘」还是「退出程序」，还可以勾上「记住我的选择，下次不再询问」。之后想改，去设置页的「关闭窗口时」。

托盘图标有三种样子：灰色 = 空闲，绿色 = 正在专注，橙色 = 暂停中。

- 鼠标停在图标上，能看到当前项目和这一轮已经专注了多久。
- 左键单击图标，把主界面叫回来。
- 右键菜单：显示主界面 / 最小化到托盘 / 暂停专注（或继续专注）/ 结束本次专注 / 退出程序。

**要真正退出程序，请用关闭按钮选「退出程序」，或者托盘菜单里的「退出程序」。**

Windows 11 默认会把新出现的托盘图标放进任务栏的「隐藏的图标」（就是右下角那个 ^ ）。想让它一直显示，点开 ^ 把它拖到任务栏上就行。

## 九、只能开一个

整个电脑同一时间只会有一个 Project Focus Manager 在跑。

如果你不小心又双击了一次 exe（比如以为程序已经关了），第二个不会真的启动起来：它会把已经在运行的那个窗口叫到前面，提示「Project Focus Manager 已经在运行，已为你打开现有窗口」，然后自己退出。这样不会出现两个程序同时往同一个数据库里写数据。

## 十、设置

- **外观**：浅色 / 深色，选完会记住，下次打开还是这个主题。
- **专注提醒**：暂停多久之后提醒你回来（5 / 10 / 15 分钟，或者不提醒）。
- **关闭窗口时**：每次询问 / 最小化到系统托盘 / 直接退出程序。
- **数据保存位置**：显示数据放在哪，可以一键打开文件夹。
- **数据备份**：点一下就在 backups 目录里存一份完整备份。

## 十一、程序异常退出怎么办

如果程序被强制关掉、电脑断电，下次打开时会出现一个「上次的专注没有正常结束」的窗口：

- 点「继续这一轮」：从现在接着往下计时。
- 点「结束这一轮」：把已经保存的时间记进项目，然后回到主界面。

程序每 15 秒会把进度写一次到数据库里，所以最多只会丢掉最后十几秒。关机那段时间不会被算进专注时间。

## 十二、安装与卸载

双击 `ProjectFocusManager-1.1.0-Setup.exe`：

1. 欢迎页点「下一步」。
2. 安装位置页可以点「浏览」换到自己想要的目录，默认是 `C:\Program Files\ProjectFocusManager`。
3. 点「安装」，装完在完成页可以直接勾选运行。

卸载：开始菜单里点「Uninstall Project Focus Manager」，或者到「设置 → 应用」里卸载。

卸载只删程序文件，`%LOCALAPPDATA%\ProjectFocusManager\dataocus.db` 里的项目和记录会留着；要彻底清掉得手动删这个文件夹。
