### 内存实测结论（详见 `docs/内存测试结果.md`）

| 状态 | 工作集（两遍） |
|---|---|
| 启动 | 144.7 / 160.8 MB |
| 专注中 | 157.6 / 160.7 MB |
| 开 ChatGPT | 611.9 / 605.1 MB（WebView2 6 进程 ≈ 445 MB） |
| 关网页后 4 秒 | 477.8 / 463.1 MB（浏览器回收窗口内，10 秒后进程归零） |
| 托盘待机 | 163.3 / 170.1 MB |

结论：WPF 基线 + 四页常驻 + WebView2 宿主决定了下限，**放弃「启动 < 60 MB」的原始目标**；关闭网页后浏览器进程实测归零，无泄漏。

### 高 DPI 局限

本机为单显示器 100% 缩放，`dpiAwareness=PerMonitorV2` 已在二进制中确认。多显示器、非 100% 缩放**未实测**（机器条件不具备）；`.tools/screens/dpicheck.ps1` 改缩放后可重测。

## 3. 界面行为实测（PowerShell + UIAutomation 脚本，脚本不进仓库）

历史实测记录（各功能开发阶段完成）：

- 5 分钟暂停提醒实测 251 秒弹出；非模态、不抢焦点
- 全屏播放器中提醒延后、退出全屏后补上（日志证据）
- 随手记：记录/标记完成/删除/重启后仍在/专注中记录自动关联会话/总结窗口显示真实想法数
- 内置 ChatGPT：启动时 WebView2 进程数 = 0；点开真实加载 chatgpt.com；关闭后进程归零
- 关闭行为三选项、托盘三态图标、悬停文字、右键菜单
- 单实例：第二次双击唤醒已有窗口并提示（提示框去重，不叠加）

**本轮新验证（发布链路）**：

- Velopack Portable.zip 解包后经启动器（`Project Focus Manager.exe` → `current\` 布局）启动正常，窗口渲染正常，数据落到兜底目录
- `ProjectFocusManager-win-Setup.exe` 静默安装：bundle 头、内嵌包、清单解析全部正确；在**本开发机**上最后一步因 `%LOCALAPPDATA%` 被 ACL 拒绝而失败——这是本机用户目录的机器特例，正常 Windows 用户目录可写，不影响正式发布

## 4. 测试不覆盖的部分（如实列出）

1. **App 层零自动化测试**：窗口、托盘、前台监听、激活应用、单实例没有 xUnit 用例（需要 UI 测试框架，成本大，已与用户确认暂不做），靠上述脚本实测。
2. **托盘图标外观与右键菜单**无法自动化断言，靠人眼确认。
3. **百度网盘/CCtalk 的真实激活**：只验证了机制（Obsidian），未逐一实测所有预置应用。
4. **安装包在真实用户机的完整安装/升级流程**：本机 `%LOCALAPPDATA%` 不可写，只能验证到 bundle 完整性一层。
5. **多显示器 / 非 100% 缩放**：未实测。
